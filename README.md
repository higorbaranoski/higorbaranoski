### 📂 Projeto em destaque

**SGPD — Sistema de Gestão de Solicitações**
Sistema desenvolvido durante a graduação em ADS para a Nexora Serviços e
Soluções, cobrindo todo o ciclo de análise:
- Mapeamento de processos com BPMN
- Levantamento de requisitos funcionais e não funcionais
- Modelagem UML (casos de uso, classes, sequência, atividade)
- Prototipação de interfaces no Figma
- Validação de usabilidade com usuário real

O objetivo foi estruturar e digitalizar o processo de registro, atribuição
e acompanhamento de solicitações de serviços.

🔗 [Repositório do projeto](https://github.com/higorbaranoski/sgpd-nexora)
